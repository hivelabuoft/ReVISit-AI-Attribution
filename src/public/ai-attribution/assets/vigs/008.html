🌐 Scenario Slide Deck — REST API Endpoint Definition

📋 The Assignment

  • Fourth-year full-stack web development course
  • Students design communication interfaces between client-side apps and server-side databases
  • Task: specify a JSON structure for a single REST API endpoint
  • The endpoint returns user profile data

😬 The Starting Point

  • Student does not know standard naming conventions for JSON keys
  • Unsure how to nest objects properly
  • Prompts an AI to generate a sample JSON response body for a user profile

🤖 First AI Output & Pushback

  • AI groups address details into a deeply nested object
  • Student argues this will complicate frontend parsing
  • Student rejects the structure, prompts AI to flatten the hierarchy

🔄 Back-and-Forth Refinement

  • AI counters with abbreviated keys to save space
  • Student requests verbose, self-documenting naming conventions instead
  • AI finally generates a clear, 15-line JSON block reflecting these choices

📤 Submission

  • Student copies the final JSON block directly into their specification document
  • The spec is submitted for peer review

📖 Original Vignette Text

In a fourth-year full-stack web development course, students learn to design communication interfaces between client-side applications and server-side databases. The assignment involves specifying a JSON structure for a single REST API endpoint that returns user profile data. The student does not know standard naming conventions for JSON keys or how to nest objects properly. They prompt an AI to generate a sample JSON response body for a user profile. The initial output groups address details into a deeply nested object, which the student argues will complicate frontend parsing. The student rejects this structure, prompting the AI to flatten the hierarchy. When the AI counters with abbreviated keys to save space, the student requests verbose, self-documenting naming conventions instead. The AI finally generates a clear, 15-line JSON block reflecting these specific architectural choices, which the student copies directly into their specification document. The spec is then submitted for peer review.
