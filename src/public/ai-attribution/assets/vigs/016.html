📖 Original Vignette Text

In a Human-Computer Interaction course, students focus on the complete design lifecycle, moving from user research to low-fidelity prototyping. The instructor assigns a comprehensive "Design Kit" project, requiring user personas, a site map, and a set of wireframe descriptions for a new travel app. The instructor assigns a comprehensive "Design Kit" project, requiring user personas, a site map, and a set of wireframe descriptions for a new travel app. The student is well-versed in design principles and capable of creating these artifacts manually but wants to save time on the documentation overhead. They prompt an AI agent to generate the entire design package, including three distinct user personas, a hierarchical site map, and textual descriptions for five key screens. Noting the coherence and completeness of the generated multi-document package, the student downloads the files and submits the whole folder without editing. The submission is evaluated based on the consistency between the user needs identified in the personas and the features proposed in the wireframes.
