📖 Original Vignette Text

In a third-year quality assurance course, the curriculum covers test planning, coverage metrics, and the distinction between unit, integration, and system testing. The assignment is to produce a test strategy document for a hypothetical flight booking system. The student is unsure how to structure such a large document and asks an AI agent to draft one. The student rejects the agent's first draft for assuming normal user traffic, prompting the AI to scrap the approach and rewrite the plan specifically for a 'Christmas holiday' scenario. They iterate multiple times, requesting the agent prioritize server survival over user interface glitches, until the logic reflects a realistic high-risk stress test. The student saves this final version and submits it as their own plan. The document serves as the blueprint for the testing phase.
