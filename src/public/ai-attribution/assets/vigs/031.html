📖 Original Vignette Text

In a third-year full-stack development course, students learn to integrate a frontend framework with a backend API and a database. The capstone assignment is to build a fully functional 'To-Do' application with user authentication. The student does not have enough knowledge to set up the required database and API routes. Thus, they use an agentic AI tool capable of generating multi-file projects and ask it to scaffold a complete application. The AI generates a folder structure containing the React frontend, Node.js backend, and MongoDB models. The student downloads the generated archive, installs the dependencies, and runs the application to verify it works. Finding that the app meets all the assignment criteria, they submit the codebase exactly as generated.
