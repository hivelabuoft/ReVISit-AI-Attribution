📖 Original Vignette Text

In a database management course, students learn to model data requirements using Entity-Relationship diagrams and SQL schema definitions. The instructor assigns a planning task to submit the text-based SQL definitions for a proposed inventory tracking system before building the actual database. The student understands exactly which columns, data types, and primary keys are required for the main 'Product' table, but wishes to accelerate the writing of syntax. They prompt a generative AI tool to produce the specific 'CREATE TABLE' statement including constraints for ID, stock count, and location fields. The AI generates a correct, ten-line SQL block that matches the student's intended structure. The student copies this snippet and pastes it directly into their design specification document without changing any variable names or types. The final design artifact is submitted for a structural review to ensure normalization rules are met.
