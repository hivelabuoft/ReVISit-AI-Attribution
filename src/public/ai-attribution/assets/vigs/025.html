📖 Original Vignette Text

In a second-year data science course, students use libraries like Matplotlib and Seaborn to generate visualizations for exploratory data analysis. The instructor assigns a task to create a dual-axis line chart comparing temperature and humidity over time from a CSV dataset. The student is unfamiliar with the syntax for creating a secondary y-axis and does not know the specific function calls. They ask a generative AI tool to provide a Python code snippet for plotting two variables on the same figure with different scales. The AI generates a twenty-line code block that reads the data and configures the axes correctly. The student copies this snippet and pastes it directly into their Jupyter notebook without modifying labels or colors. The notebook is run to produce the chart, which is then exported for the assignment submission.
