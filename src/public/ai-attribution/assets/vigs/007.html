📖 Original Vignette Text

In a second-year object-oriented programming course, students learn to model real-world systems using inheritance, polymorphism, and encapsulation. The instructor assigns a planning task to create a UML class diagram for a library management system involving books, patrons, and loans. The student is unsure about how to represent the relationships between the 'Loan' class and the 'Patron' class. They use a generative AI tool to produce a text-based PlantUML snippet for these specific classes and their attributes. The AI generates a concise, correct UML diagram defining the classes and their association. The student pastes the snippet into their design document as-is and submits it as the planning deliverable. The artifact is submitted as a planning deliverable before any actual coding begins.
