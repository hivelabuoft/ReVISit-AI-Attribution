🐛 Scenario Slide Deck — Debugging a Logic Error

📋 The Assignment

  • First-year programming course
  • Students are given a mostly working script that calculates the average of a list of grades
  • The script produces incorrect results
  • Task: identify the logical error in the loop accumulation step and correct it

😟 The Student's Struggle

  • Student is unfamiliar with common accumulator patterns
  • Sees the output is wrong but cannot determine why
  • The total sum is lower than expected

🤖 Asking the AI

  • Student asks an AI tool to explain how the accumulation variable is behaving in the provided code snippet
  • AI explains: the variable is being reset to zero inside the loop instead of outside
  • This causes the variable to forget previous values

🔧 Applying the Fix & Result

  • Student reads the explanation and locates the specific line of code mentioned
  • Moves the initialization line exactly as described by the AI
  • The corrected script is run and produces the right average

📖 Original Vignette Text

In a first-year programming course, students are given a mostly working script that calculates the average of a list of grades but produces incorrect results. The assignment requires students to identify the logical error in the loop accumulation step and correct it. The student, unfamiliar with common accumulator patterns, sees that the output is wrong but cannot determine why the total sum is lower than expected. They ask an AI tool to explain how the accumulation variable is behaving in the provided code snippet. The AI explains that the variable is being reset to zero inside the loop instead of outside, causing it to forget previous values. The student reads this explanation, locates the specific line of code mentioned, and moves the initialization line exactly as described by the AI. The corrected script is then run and produces the right average.
