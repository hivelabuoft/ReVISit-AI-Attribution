📖 Original Vignette Text

In a distributed systems course, students learn to containerize applications and orchestrate them using Kubernetes (a popular platform for distributed services). The task is to write multiple configuration files to deploy a frontend and backend service. The student understands how to write these configurations manually but wants to avoid typing out the long, repetitive code blocks. The AI initially proposes a layout optimized for low cost, but the student rejects this, engaging in multiple rounds of prompting to request a high-availability architecture instead. The student critiques the AI's logic on server backups until the design meets their reliability standards. The student accepts the revised files and applies them to the cluster without making any manual edits to the text. The deployment configuration works correctly upon execution.
