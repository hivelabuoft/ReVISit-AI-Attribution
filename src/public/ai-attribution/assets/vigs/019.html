📖 Original Vignette Text

In a first-year introductory Python course, students learn how to process text data using built-in string methods and loops. The assignment requires writing a function that checks if a password string meets specific complexity requirements, such as containing digits and uppercase letters. The student is unsure how to check each character in the string individually and asks an AI tool to explain the logic of string iteration. The AI provides a conceptual explanation of using a 'for' loop to visit every character and checking its type with helper methods. The student reads the explanation and types out the code logic exactly as described by the AI, translating the English steps directly into Python syntax. They follow the AI's described steps exactly and do not add extra checks or alternative logic. The code is saved and run against the local test suite.
