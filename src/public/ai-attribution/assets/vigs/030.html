📖 Original Vignette Text

In a third-year systems programming course, students work with raw memory and binary file formats to understand data representation. The assignment is to write a C function that reads a custom binary header containing integers and flags. The student is proficient in C but uses an AI to generate the 'fread' boilerplate code to save time. The AI produces a standard 15-line function that reads the bytes into a struct. The student takes this code and significantly modifies it to fix how the raw data is interpreted, which the AI omitted, and adds a robust error-checking layer to verify the file is the correct type. They also integrate the function into a larger state machine they wrote previously. The final artifact is a highly specialized parser that notably extends the functionality of the initial generated snippet. The student then submits the file for grading.
