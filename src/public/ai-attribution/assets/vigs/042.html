📖 Original Vignette Text

In a third-year security engineering course, students practice auditing code for common web vulnerabilities like SQL injection. The assignment provides a PHP script with an insecure database query and asks the student to secure it. The student, relying on their security engineering background, identifies the lack of input sanitization and asks an AI to explain the best defense against this specific attack. The AI explains the concept of Prepared Statements and how they separate data from code. The student agrees but decides that Prepared Statements alone are not enough for this legacy system. They manually implement a comprehensive input validation layer and a custom error logging module, in addition to the prepared statement AI suggested, integrating the AI's core advice into a much larger security framework they design themselves. The final submission includes the patched file and a report detailing the extensive manual changes.
