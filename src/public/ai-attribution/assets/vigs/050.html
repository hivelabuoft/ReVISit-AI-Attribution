📖 Original Vignette Text

In a third-year software testing course, students are given a completed web application and must generate a comprehensive test suite. The student, don't know how to test the program, uses an AI agent to scan the codebase and generate test files for all the major components. The agent produces a standard set of tests, but the student rejects them for having insufficient coverage. The student directs the agent to rewrite the suite to simulate a 'hostile user' trying to break the input fields. After reviewing the new output, the student iterates a couple of more times, refining exactly which error messages count as a successful test, until the logic matches their expectations. The student accepts the updated suite and submits the files, using the agent's generated code from the final prompt.
