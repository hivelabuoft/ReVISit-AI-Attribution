💡 The Starting Point

  • Instead, asks an AI agent to perform the refactoring

🤖 First AI Proposal — Rejected

🔄 Further Iteration

📖 Original Vignette Text

In a fourth-year distributed systems course, students deal with large codebases that need to be modularized for better scalability. The task is to split a monolithic 'Server' file into separate modules for networking, storage, and logic. While understanding the task and confident to do it by hand, the student asks an AI agent to perform this refactoring. The agent proposes grouping files by technical layer (e.g., database vs. logic), but the student rejects this, reasoning it makes the system harder to scale. The student prompts the agent to reorganize by 'feature' instead. When the agent complies but uses vague folder names, the student iterates more times to enforce strict naming conventions and coding style. The student verifies the imports are correct and accepts the refactored project structure. The code is compiled to ensure no dependencies were broken.
