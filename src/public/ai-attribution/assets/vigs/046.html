📖 Original Vignette Text

In a third-year mobile development course, students are required to write unit tests for their utility functions to ensure app stability. The student has written a function that formats currency strings but hasn't written the test cases yet. They are proficient in the testing framework but aim to expedite the process. They paste the function into an AI tool and ask it to generate a standard test case for negative numbers. The AI outputs a correct, twenty-line test function using the standard assertion library. The student reviews the code, sees that it covers the necessary logic, and pastes it directly into their test suite file. The tests are run locally and pass without issue, completing the requirement for that specific function.
