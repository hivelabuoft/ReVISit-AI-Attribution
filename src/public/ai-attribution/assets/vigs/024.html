📖 Original Vignette Text

In a third-year computer networks course, students implement application-layer protocols using Python's socket library to understand TCP connections. The assignment is to build a simple echo server that can handle multiple concurrent client connections. The student is comfortable with basic sockets but asks an AI to explain the theoretical differences between using 'select' and threading for concurrency. The AI provides an adequate explanation. The student begins writing the code based on this concept but later decides to use a thread-pool architecture for better scalability on their specific hardware. They pivot away from the AI's logic, writing a completely different implementation using the 'concurrent.futures' module and adding custom signal handling. The final submission uses a diverse set of libraries and logic that diverges significantly from the initial 'select' explanation.
