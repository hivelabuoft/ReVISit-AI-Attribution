📖 Original Vignette Text

In a fourth-year course on programming language design, students learn how to build software that reads and executes code. The project requires building an interpreter for a small custom language that handles math operations and variables. The student understands the necessary logic well but asks an AI agent to generate the complete multi-file starter code to save setup time. The AI generates a fully functional set of files that can process simple commands. The student reviews the code and decides to delete the core processing logic, manually rewriting it to handle complex mathematical rules and custom error messages that the AI missed. The final submission uses the file structure provided by the AI but runs on the student's heavily modified code.
