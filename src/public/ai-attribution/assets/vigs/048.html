📖 Original Vignette Text

In a fourth-year systems programming course, students are updating old code to be more efficient. The task is to replace a slow, manual loop that searches for data with a standard, modern library function. The student, having mastered the relevant optimization theory, asks an AI to help fix the loop, and the AI generates a simple, one-line standard command to replace it. The student takes this basic command but decides to make it high-performance by splitting the work across multiple computer processor cores (multithreading). They manually write the complex surrounding code to manage memory safely and prevent crashes—logic the AI did not provide. The final submission is a sophisticated, fast program where the AI's simple snippet serves only as a building block.
