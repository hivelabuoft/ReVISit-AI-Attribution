📖 Original Vignette Text

In a second-year introductory data analysis course using Python, students learn to manipulate dataframes with pandas. The student is stuck on a syntax error where they try to filter rows based on a condition, but the code throws a 'KeyError'. The student does not have enough knowledge to understand why the column name is not recognized. They paste the error message and the crashing line into an AI tool, asking for a fix. The AI generates a corrected single line of code, showing that the student missed a necessary set of brackets for the boolean indexing. The student recognizes the correction, copies the line, and pastes it over their broken code. The script runs successfully, producing the filtered dataset required for the next step of the analysis.
