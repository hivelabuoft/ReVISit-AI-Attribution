📖 Original Vignette Text

In a third-year algorithms course, students compare iterative and recursive solutions to tree traversal problems. The assignment asks students to refactor an existing iterative graph search function into a recursive one. The student understands the logic but asks an AI to generate the recursive helper function to handle the state passing. The initial AI output works but does not match the student's coding style. Instead of editing the code manually, the student rejects the output, iteratively prompting the AI to remove external dependencies, enforce specific variable naming conventions, and condense the logic into fewer lines. After rounds of refining the prompt until the syntax is precise, the student accepts this refined version and replaces their old iterative loop with the generated recursive logic. The refactored code is tested against the graph traversal test cases.
