📖 Original Vignette Text

In a third-year machine learning course, students learn to build pipelines for data loading, model definition, training, and evaluation using PyTorch. The assignment is to train a Neural Network on a popular dataset to achieve a specific accuracy. The student is capable of writing the code but wants to save time on the boilerplate setup. They ask an AI agent to generate the full training script, including data augmentation and the evaluation loop. The AI produces a comprehensive Python project and a requirements file. The student reviews the architecture defined by the AI, sees it is a standard ResNet implementation that fits the requirements, and runs the script. Satisfied with the results, the student submits the generated files directly to the grading system.
