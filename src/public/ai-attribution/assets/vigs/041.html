🛠️ Scenario Slide Deck — Code Smell Refactoring

📋 The Assignment

  • Third-year software engineering course
  • Focus: improving code maintainability by identifying "code smells"
  • Examples of smells: duplicate logic, overly long functions
  • Task: critique and refactor a 200-line method into smaller, more cohesive helper functions

🔍 Recognizing the Problem

  • Student applies established modular design principles
  • Recognizes the method is too long
  • Consults an AI for a cleanup strategy

🤖 First AI Suggestion — Rejected!

  • AI suggests splitting the code by data type
  • Student rejects this approach
  • Reason: it breaks the user workflow

🔄 Iterating & Steering the AI

  • Student directs AI to organize logic based on "user roles" instead
  • AI's next proposal creates too many small fragments
  • Student instructs AI to consolidate into three strict categories

🚀 Final Refactor & Submission

  • AI outlines the final structural logic
  • Student performs the refactor, strictly executing the grouping map the AI produced
  • Refactored code is submitted for a peer review session

📖 Original Vignette Text

In a third-year software engineering course, students learn to improve code maintainability by identifying 'code smells' like duplicate logic or overly long functions. The task is to critique and refactor a 200-line method into smaller, more cohesive helper functions. The student, applying established modular design principles, recognizes the method is too long and consults an AI for a cleanup strategy. The AI suggests splitting the code by data type, but the student rejects this, noting that it breaks the user workflow. The student directs the AI to instead organize the logic based on 'user roles.' When the AI's next proposal creates too many small fragments, the student instructs it to consolidate the plan into three strict categories. The AI outlines the final structural logic, and the student performs the refactor, strictly executing the specific grouping map the AI produced. The refactored code is submitted for a peer review session.
