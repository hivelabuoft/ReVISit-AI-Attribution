📱 Scenario Slide Deck — Responsive Menu Layout

📋 The Assignment

  • Introductory web design course
  • Students learn to build sites for both mobile phones and desktops
  • Task: create a menu bar that automatically hides certain buttons when the screen is narrow

😟 The Starting Point

  • Student does not understand the underlying mechanism for detecting screen width changes
  • Asks the AI for a logic guide

🤖 First AI Interaction

  • AI initially suggests to simply stack the buttons
  • Student rejects this suggestion
  • Student prompts the AI to describe a "sliding" effect instead

🔄 Iterating with the AI

  • Multiple iterations to refine how the movement should behave
  • Process continues until the AI provides a precise logic flow
  • Final logic flow matches the student's specific vision

🚀 Coding & Submission

  • Student manually writes the code
  • Code is written by strictly translating the AI's text instructions
  • Completed work is uploaded to the course server for grading

📖 Original Vignette Text

In an introductory web design course, students learn to build sites that work on both mobile phones and desktops. The instructor assigns a task to create a menu bar that automatically hides certain buttons when the screen is narrow. The student does not understand the underlying mechanism for detecting screen width changes. They ask the AI for a logic guide but rejects the AI's initial suggestion to simply stack the buttons. The student prompts the AI to describe a 'sliding' effect instead, iterating multiple times to refine how the movement should behave. Once the AI provides a precise logic flow that matches the student's specific vision, the student manually writes the code by strictly translating the AI's text instructions. The completed work is uploaded to the course server for grading.
