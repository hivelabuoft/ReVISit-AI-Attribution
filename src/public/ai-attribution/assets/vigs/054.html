📖 Original Vignette Text

In a third-year front-end engineering course, students learn how to modernize aging web applications. The task is to migrate a website's code from an outdated structure to a newer, modern standard. The student, possessing deep knowledge of component rendering cycles, still uses an AI agent to 'translate' the code components into the new style. While the AI successfully updates the syntax, the student realizes the AI's version causes the website to 'stutter' (lag) because it tries to refresh the screen too often. The student manually redesigns the logic for how data is shared across the app to fix this performance issue. This involves a structural repair the AI did not suggest, and fixes visual glitches the AI missed. The final result blends the AI's basic translation with the student's extended architectural improvements.
