📖 Original Vignette Text

In a third-year cybersecurity course, students learn to use automated tools to scan applications for known vulnerabilities. The assignment asks the student to audit a provided web app and fix any critical issues. The student, using specialized knowledge from the course, instruct and runs a specialized AI security agent that scans the code, identifies three high-severity dependency flaws, and generates a 'Pull Request' with the updated package versions and necessary code patches. The student then reviews the changes, recognizing them as standard security updates, and accepts the agent's patches without modification. The student submits the secure codebase along with the agent's audit report.
