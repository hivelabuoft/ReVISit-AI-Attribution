📖 Original Vignette Text

In a third-year mobile application course, students focus on building Android apps that consume external APIs and display data in a list format. The project requires building a simple weather application that fetches data based on user location. The student lacks experience with asynchronous network calls and asks an AI agent to generate the entire project structure. The agent produces a standard list-based interface, but the student notes that the design is too cluttered. They reject the layout, prompting the agent to rebuild the app using a minimalist 'card-swipe' interaction instead. The student further modifies the AI's color choices, iterating through distinct style prompts until the contrast meets their accessibility standards. The student downloads the agent's final code package and submits it directly.
