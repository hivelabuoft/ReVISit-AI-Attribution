📖 Original Vignette Text

In a second-year computer networks course, students explore application-layer protocols using simple text-based formats. The instructor assigns a conceptual task to design a message format for a basic chat application, specifying how the client and server should exchange data. The student understands how to structure basic messages but wonders if a binary format would be more efficient than a text-based one. They ask an AI chatbot to explain the conceptual trade-offs between binary formats and plain text protocols like JSON. The AI provides a clear explanation favoring binary for speed, detailing how to pack bytes efficiently to save space. The student reads this but decides a binary format is too complex for debugging, so they manually design a detailed JSON-based structure that includes extra fields for encryption and timestamps not discussed by the AI. The final protocol specification is submitted as a text document and will be evaluated on clarity and feasibility.
