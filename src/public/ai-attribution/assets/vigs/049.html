📖 Original Vignette Text

In a third-year DevOps course, students manage automated build pipelines that run tests whenever code is pushed to a repository. The student's pipeline is failing with an obscure error related to environment variables. Lacking deep knowledge of the YAML configuration syntax, the student grants an AI agent access to the repository logs to diagnose the fix. The agent analyzes the failure and generates a patched version of the entire CI configuration file, correcting the variable scope. The student reviews the diff, sees the next pipeline run succeeds, and commits the file exactly as generated. The pipeline runs successfully on the next push, resolving the assignment issue without additional changes beyond applying the agent's fix.
