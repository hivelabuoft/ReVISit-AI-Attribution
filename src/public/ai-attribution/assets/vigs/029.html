📖 Original Vignette Text

In a data visualization course, students learn to present complex data clearly using Python libraries like Matplotlib. The instructor assigns a small exercise requiring a bar chart that compares quarterly sales figures with specific labeling requirements. The student is fully capable of writing the plotting code from scratch but decides to use an AI tool to speed up the syntax generation. They prompt the AI to create the chart, but the first result lacks the necessary grid lines and uses the wrong color scheme. The student rejects this version and prompts the AI again, specifically requesting dashed grid lines and a distinct pastel color palette. The AI regenerates the code block to match these precise stylistic instructions. Satisfied with the visual preview, the student copies the final code snippet and pastes it directly into their submission file without changing a single character. The completed chart is rendered and submitted for the visual grade.
