🧹 Scenario Slide Deck — Linting & Formatting

📋 The Assignment

  • Third-year full-stack web course
  • Instructor emphasizes code style & consistency using ESLint
  • Task: refactor a functioning but messy code block
  • Goal: meet strict readability standards

😟 The Starting Point

  • Student doesn't know how to start improving code style
  • Asks an AI to clean up the code

🤖 First AI Output — Rejected

  • AI returns code using "shorthand" syntax
  • Student feels it's too advanced to maintain
  • Rejects this and prompts AI to rewrite using beginner-friendly logic

🔄 Iterating for the Right Balance

  • AI's beginner-friendly version turns out too verbose
  • Student iterates a third time
  • Requests a version that is concise yet explicitly clear
  • Satisfied with this specific balance

✅ Submission Outcome

  • Student accepts the final AI version without manual edits
  • Pastes it into the project, replacing the original messy file
  • Submission now passes the course's automated style checker

📖 Original Vignette Text

In a third-year full-stack web course, the instructor emphasizes code style and consistency using tools like ESLint. Students must refactor a functioning but messy code block to meet strict readability standards. The student, who doesn't know how to start improving code style, asks an AI to clean up the code. But the initial output uses 'shorthand' syntax that the student feels is too advanced to maintain. The student rejects this, prompting the AI to rewrite it using beginner-friendly logic. When the AI returns a version that is too verbose, the student iterates a third time, requesting a version that is concise yet explicitly clear. Satisfied with this specific balance, the student accepts this version and pastes it into the project, replacing the original messy file. The submission now passes the course's automated style checker.
